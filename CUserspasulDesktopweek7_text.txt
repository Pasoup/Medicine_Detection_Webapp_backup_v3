2.  สิ่งที่ได้ดำเนินการในสัปดาห์นี้
2.1  Frontend JWT Authentication — LoginPage.jsx และ api/index.js
เดิม LoginPage.jsx ใช้การตรวจสอบ username/password แบบ hardcode ภายใน component โดยตรง สัปดาห์นี้ได้เปลี่ยนให้เรียก API จริง และ api/index.js ให้แนบ Bearer token ทุก request:
LoginPage.jsx — เพิ่ม handleSubmit() ที่ POST {username, password} ไปยัง /auth/login ด้วย fetch()
เมื่อ Login สำเร็จ — เก็บ access_token ลง localStorage ภายใต้ key "access_token" และเรียก onLogin({ username, role })
เพิ่มการตรวจ res.ok หัง .then() แรก เพื่อจับ 401/404 จาก Backend และแสดงข้อความ error ที่ถูกต้อง
api/index.js — เพิ่ม token_helper() ที่อ่าน token จาก localStorage และคืน headers object { Authorization: Bearer ..., Content-Type: application/json }
ใส่ token_helper() เป็น headers ให้กับทุก fetch() call ในไฟล์ ยกเว้น /auth/login ที่ไม่ต้องการ token
/video_feed ไม่ต้องการตรวจสอบ — โปรแกรม MJPEG โลดผ่าน <img src> ซึ่งไม่สามารถแนบ header ได้ จึงยกเว้นไว้โดยเจตนา
2.2  ฟีเจอร์ Hospital Location — SetupPage.jsx, database.py, server.py, App.jsx, HistoryPage.jsx
เพิ่มฟีเจอร์บันทึก Location ของโรงพยาบาลลงในทุก scan session เพื่อให้ History Page แสดงว่าสแกนทำที่ใด โดยดึงข้อมูลจากหน้า Setup ที่มีอยู่แล้ว การเปลี่ยนแปลงที่สำคัญ:
SetupPage.jsx — เพิ่มการโหลด hospitalName และ hospitalCode จาก localStorage เป็นค่าเริ่มต้น state (ใช้ default ถ้ายังไม่เคยบันทึก)
SetupPage.jsx — handleSave() เพิ่มการ localStorage.setItem("hospital_name") และ localStorage.setItem("hospital_code") ทุกครั้งที่กด Save Settings
database.py — เพิ่ม column location TEXT ใน CREATE TABLE scan_sessions และ run ALTER TABLE เพื่อเพิ่ม column ให้ database เดิมที่มีอยู่แล้ว
server.py — เพิ่ม location ให้ SaveHistoryPayload model และใส่ลงใน INSERT INTO scan_sessions ของ POST /history รวมถึง GET /history คืน location ใน response
App.jsx — อ่าน localStorage.getItem("hospital_name") และใส่เป็น location ใน entry ทั้ง handleCloseAndReview() และ handleComplete()
HistoryPage.jsx — เพิ่ม <td> สำหรับ item.location ในตาราง History ที่มีหัวคอลัมน์ Location อยู่แล้ว
